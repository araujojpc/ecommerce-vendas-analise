# Análise de Vendas — E-commerce

## 📌 Objetivo
Análise exploratória de dados de vendas de um e-commerce para responder:
**"Onde estamos perdendo dinheiro e quais clientes devemos priorizar?"**

## 🗂️ Fonte dos dados
- Dataset: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
- Período: 2016–2018
- Tabelas utilizadas: pedidos, clientes, itens, avaliações

## 🛠️ Ferramentas
Python · Pandas · NumPy · SQL (SQLite) · Matplotlib · Seaborn · Plotly · Git

## 📁 Estrutura do projeto
data/ → dados brutos (baixar do Kaggle)
notebooks/ → análise exploratória
scripts/ → código reutilizável
sql/ → queries de negócio
outputs/ → gráficos e relatórios
